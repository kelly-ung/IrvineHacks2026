# IrvineHacks2026

## Xylem
Xylem is a website that allows users to browse and filter through a database of 350+ plant species, each with growth and care information. 
Every plant profile includes data such as growth rate, sunlight requirements, soil type, fertilization needs, and care difficulty. 
Our filters make it easy to find relevant results based on these characteristics.
